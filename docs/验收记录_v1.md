# v1.0.0 验收记录

日期 2026-10-20。环境为 Windows 11 x64、Python 3.14、200% 系统缩放，CPU 推理。

## 实际验证

- 禁用 Python socket 后调用真实 OCR，仍成功识别中英文、数字；4 行样张首次加载加识别约 3.38 秒，仅代表本机该样张。
- 中文文件名、空白图、损坏图、透明背景转白、UTF-8 TXT 导出。
- Qt 窗口中的剪贴板图片、结果编辑和复制、历史切换、清空记录、失败后继续处理后续图片。
- 合成冻结画面上的选区鼠标操作与裁剪尺寸。
- 浅色、深色界面与高 DPI 渲染。
- Windows 全局快捷键注册、WM_HOTKEY 消息分发；没有模拟其他应用中的物理按键完整流程。
- 最终无控制台 EXE 独立启动，窗口可见、响应正常，内置模型成功识别中文路径样张，进程正常退出。

## 边界

识别以横排中英文为主，未进行复杂表格、竖排、公式或低清图片准确率评测。多显示器采用各屏 DPR 处理，但尚未完成多屏组合实机验收。首次识别耗时会随硬件与图片变化。
