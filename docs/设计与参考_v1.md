# 拾字 v1 设计与参考

2026-10-20。目标是把「截图 → 识别 → 复制」收敛为一个工作台。

参考 Umi-OCR README，关注截图、剪贴板输入、批量图片和结果编辑流程；其他功能不进入第一版。应用与视觉独立实现。

固定左侧会话栏，主区双栏对照原图与文字。识别结果直接可编辑，复制常驻。低饱和绿色只用于主要动作与完成状态；浅灰背景与留白承担层级。使用系统字体、标准窗口边框、原生文件对话框与可键盘操作控件。支持浅色与深色、系统缩放以及可调双栏宽度。最小 960×640，适用于本机桌面。

错误显示在底部状态栏；空白图片与损坏文件区分处理。OCR 在工作线程执行，逐张排队，失败不会阻塞后续图片。记录仅驻留内存，最多 100 条，避免长期积累图片。大于 4000 万像素的图片拒绝处理；最长边超过 5000 的输入会缩小。显示预览最长边 1600，不改变识别原件。
