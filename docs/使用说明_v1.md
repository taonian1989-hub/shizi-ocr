# 拾字 v1.0.0 使用说明

从 GitHub Releases 下载 Windows x64 便携包，解压整个文件夹，双击「拾字/拾字.exe」。无需 Python、API Key 或联网。请保留同目录所有文件。

Ctrl+Alt+S 截图识别；Ctrl+O 打开图片；Ctrl+V 粘贴图片；Ctrl+Shift+C 复制全文；Ctrl+S 保存 TXT。拖动选择截图区域，Esc 或右键取消。

也可以直接把图片拖入窗口，支持多张排队。结果可以编辑，左侧切换本次记录。左下角切换浅色与深色。

「新的识别」清空当前工作区，已有结果保留在本次记录中；「清空」删除本次全部记录。关闭窗口即退出，退出后不保留记录。识别进行中请等待完成再关闭。

核心功能为横排中英文图片识别，不含 PDF、二维码、公式或复杂版面还原。首次加载引擎可能稍慢。快捷键被占用时，仍可使用截图按钮。

图片与文字不上传；主动导出文件与 Windows 剪贴板由用户控制。一次会话最多 100 条，超过 4000 万像素请先裁剪；最长边超过 5000 像素会缩小处理。

当前运行目标为 Windows 11 x64，最小窗口 960×640 逻辑像素。多屏单次选区限于一块显示器，多显示器组合尚未进行实机验收。
